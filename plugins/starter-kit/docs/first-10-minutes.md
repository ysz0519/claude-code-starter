# 最初の10分の使い方

Claude Code（＝ターミナルで動く Claude。あなたの Mac のファイルを読み書きし、コマンドを実行できる）を入れた直後に、これだけ知っていれば困らないことをまとめた。

## 1. 起動

```bash
cd ~/Documents/作業するフォルダ   # 作業したいフォルダに移動してから
claude                           # 起動（初回はブラウザでログイン）
```

- Claude は「起動したフォルダの中」を作業場所として扱う。関係ないフォルダ（ホーム直下など）で起動すると、何でも触れてしまうので避ける
- 終了は `/exit` か Ctrl+C を2回
- 前回の続きから再開するときは `claude -c`（同じフォルダで）

## 2. 最初の頼み方

日本語で、やってほしいことを「何を・どうしたいか・できあがりの形」で書く。

```
このフォルダの PDF を全部読んで、会社ごとに1行の要約を summary.md にまとめて
```

- うまくいかなかったら、エラーの文をそのまま貼って「直して」と言えばよい
- 大きな作業は、先に「やり方を考えて」と頼むか、プランモード（下の 3）にしてから始める

## 3. 困ったときの3つ

| 状況 | 打つもの |
|---|---|
| 話題を変える・前の作業の文脈を持ち越したくない | `/clear`（会話をまっさらにする。設定は消えない） |
| 会話が長くなって動きが鈍い・文脈の使用率（ステータスラインの ctx）が 80% を超えた | `/compact`（会話を要約して軽くする） |
| さっきの変更を戻したい | `/rewind`（指定の時点までファイルと会話を巻き戻す） |

## 4. プランモード（先に段取りを見てから実行させる）

Shift+Tab を押すとモードが切り替わる。「plan」にすると、Claude はファイルを読んで段取りを示すだけで、編集やコマンドは実行しない。段取りに納得したら「進めて」と言う（モードは自動で戻る）。
3ステップ以上の作業、初めての種類の作業は、まずプランモードで頼むと失敗が減る。

## 5. 許可を聞かれたら

Claude が何かを実行する前に「許可しますか」と聞いてくることがある（頻度はセットアップで選んだ「確認の頻度」で決まる）。

- 内容を読んで Yes / No を選ぶ。「このセッションでは今後聞かない」を選ぶと同じ種類の操作は聞かれなくなる
- セットアップで入れた安全弁（`~/.claude/settings.json` の `deny`）は、どのモードでも先に止める: `sudo`・`rm -rf` でホームを消す・`git push --force`・`.env` や鍵ファイルを読む
- 確認の頻度を変えたいときは `/starter-kit:setup` で選び直す（設定の正体は `permissions.defaultMode`）

## 6. 引き継ぎ書（離席・翌日の再開）

長い作業を中断するときは、こう頼む。

```
ここまでの作業の引き継ぎ書を HANDOVER.md に書いて。目的・やったこと・残り・次にやる最初の1手・関連ファイル、の5項目で
```

翌日は新しいセッションで `HANDOVER.md を読んで続きをやって` と言えば再開できる。会話を使い回すより軽く、速い。

## 7. ステータスラインの読み方（画面の一番下）

```
作業フォルダ | モデル | effort:high | $1.23(API換算)
ctx ████████░░░░░░░░░░░░ 42%  5h:24%(↻1h20m)  7d:81%(↻2d7h)
git main +12 -3
```

- `ctx`: 会話の文脈をどれだけ使ったか。黄（60%）で `/compact` を考え、赤（80%）なら `/compact` か `/clear`
- `$`: このセッションを API 料金に換算した累計。定額プラン（Pro/Max）なら実際の請求ではなく目安
- `5h` / `7d`: プランの使用量の枠（5時間ごと・7日ごとに戻る）と、戻るまでの時間。赤に近づいたら休憩か `/compact`
- `effort`: 考える深さ（`/effort` で変えられる。普段は medium〜high）

## 8. よく使うコマンド

| コマンド | 何が起きるか |
|---|---|
| `/help` | コマンド一覧 |
| `/config` | 設定画面（テーマ・通知・モデルなど） |
| `/model` | モデルの切り替え（普段は既定のまま。難しい設計だけ上位モデルにする） |
| `/terminal-setup` | Shift+Enter で改行できるようにターミナルを設定する（iTerm2・Terminal.app） |
| `/memory` | Claude に覚えておいてほしいこと（CLAUDE.md）を編集する |
| `/mcp` | 外部サービスとの接続口（MCP）の状態と認証 |
| `/chrome` | Claude in Chrome 拡張の接続状態 |
| `/usage` | プランの使用量 |
| `/starter-kit:status` | 初期セットアップの現状表 |

ターミナルで `claude doctor` と打つと、インストールの健康診断ができる。

## 9. Claude に覚えさせたい作法

`~/.claude/CLAUDE.md`（全プロジェクト共通）と、作業フォルダの `CLAUDE.md`（そのプロジェクトだけ）に書いたことを、Claude は毎回読む。
セットアップで入れた「話し方・やらないこと」の区間はそのまま残し、下に自分のルールを足していく（例: 「ファイル名は日付を先頭に」「報告は3行以内」）。
Claude に「これを覚えて」と言えば、Claude が自分で CLAUDE.md に書き足す。
